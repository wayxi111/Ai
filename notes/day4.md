## 第 5 集：行列式 (The determinant)

### 行列式的几何含义（一句话）

- det(M) 度量的是：_（在二维空间下）面积缩放的比例，或者说在该维度下描述其大小的最大标准的缩放比例_____
  （提示：一个单位正方形被 M 变换后，面积变成多少？）

### 符号的语言

- det > 0：空间定向 _右手系_____（右手系还是右手系）
- det < 0：空间定向 _左手系_____（就像把纸翻了个面）
- 二维里"翻转"的直观画面：_❎i-hat转变为负方向❎
>变换后 î 到 ĵ 的旋转方向从逆时针变为顺时针

### 特殊情况

- det(M) = 0 意味着：_平面被压缩成一条直线_____
  （提示：面积被压成 0，说明整个平面被压成了一条______或一个______）
- 这和 Day 2 的哪个概念遥相呼应？_线性相关/共线_____

### 三维的情形

- det 在三维度量的是 _体积_____ 的缩放
- det 为负时，类似把一个手套 _镜像_____

### 动手算（纸笔）

- det([[3, 0], [0, 2]]) = _6_____，几何上发生了什么？_i-hat缩放为原来三倍，方向不变，j-hat缩放为原来二倍，方向不变，表示的矩形面积变为原来六倍_____
- det([[1, 2], [2, 4]]) = _0_____，为什么？_i-hat和j-hat在几何上被变为共线的向量了_____

### 我的疑问 / 卡点

-
>疑问一：在det<0的时候我不清楚怎么判断图形向哪里翻转了
- 答：直接的结论比较难写，可以参考左右手系，i-hat与j-hat的时针关系
>疑问二：课后的思考题，如何解释det（M1）det（M2）= det（M1M2）？我的理解是在几何上的作用与day3的内容相似，先缩放再缩放和一步走完缩放效果是一样的 
- 答：先经历 M₁ 再经历 M₂时，总面积缩放率是两个缩放率的乘积。你嘴上说的“先缩放再缩放”，其实方向是对的！但注意一个细节：**面积缩放率会相乘，但变换本身不可交换**——det 公式成立恰恰因为“数可以相乘，顺序无关”，而矩阵乘法本身顺序有关。
这个对比很妙：
**M₁M₂ ≠ M₂M₁（变换顺序改变结果）det(M₁M₂) = det(M₂M₁)（但面积的缩放率怎么乘都一样）**

## 第 6 集：逆矩阵、秩、列空间 (Inverse matrices, column space and null space)

### 线性方程组的变换视角

- Ax = v 的全新读法：x 经过变换 A 后落在了 v 上，求 x
- 两种可能的结果：落在 v 上 的向量有 _1_____ 个 / _无限_____ 个 / _0_____ 个

#### Ax = v 元素的身份表

| 符号 | 身份 | 生活在哪 | 关键性质 |
|---|---|---|---|
| **A** | 变换本身 | 变换前空间 → 变换后空间 | 固定不动，是"题目"的一部分 |
| **x** | 未知**向量** | **变换前**的空间 | 整个方程唯一被追问的东西 |
| **v** | 已知**向量** | **变换后**的空间 | 落点，是"题目"给的答案侧信息 |
| **Ax** | 已知变换作用于未知向量 | 变换后的空间 | 它**必须等于** v，这就是方程本身 |

三个易混点：

1. **x 是"配方"，不是"箭头"**：x 的坐标是"x 份 î + x 份 ĵ"的配方比例。方程读作：怎样混合 A 给的新原料（新 î、新 ĵ），才能调出 v 这杯成品？求解方程 = 反推配方
2. **x 和 v 在不同的世界里**：都是 2 个数，但 x 的坐标是**变换前**基向量的比例，v 的坐标是**变换后**（标准基下的）坐标。它们的关系要**经过 A 才能建立**
3. **"落点"是 A@x 的，不是 A 的**：A 知道新原料（列 = 基向量落点）【矩阵的"变换"身份】；A 的列是新原料本身【矩阵的"数据"身份】；A@x 是按配方 x 混合新原料的成品；v 是目标成品；方程是"成品 == 目标"的约束

三种解的情形（用身份语言重读三分法）：

- **det(A) ≠ 0**：A 是双射——变换后空间每个点恰好被一个变换前点占据。给定成品 v，**唯一**存在一份配方 x 能调出它。这就是"A⁻¹ 存在"和"解恰好 1 个"是同一件事的原因
- **det(A) = 0 且 v 在列空间里**：成品可达，但多种配方压到同一成品（信息被压缩合并）。多出的自由度 = 零空间的维度
- **det(A) = 0 且 v 不在列空间里**：成品根本调不出来——v 不在 A 的"菜单"（列空间）上

一行代码自证：

```python
import numpy as np
A = np.array([[2., 1.], [1., 3.]])
x = np.array([1.5, -0.5])           # 任取一份"配方"
v = A @ x                            # 成品
print(np.linalg.solve(A, v))         # [1.5, -0.5] —— 从成品反推出配方，唯一
```

### 逆矩阵

- A⁻¹ 的几何含义：_将向量逆变换_____
- A⁻¹A = _[[1, 0], [0, 1]]_____，为什么？_几何意义上作用相互抵消，等价于什么都不做**先施加 A，再施加A⁻¹，从右往左读。A 把空间变换过去，A⁻¹ 把它原样变回来，复合起来 = 什么都不做 = 恒等变换。而恒等变换的矩阵就是 I**_____
- det(A) = 0 时逆矩阵为什么不存在？_det = 0时造成了向量降维，某一个维度信息被消除，我们无法逆向还原出这个维度的信息_____
  （提示：你已经不能从一条直线"解压"回整个平面了——信息丢了）

### 秩 (rank)

- 秩的几何含义：变换后 _实际到达的空间_____ 的维数
- 秩为 1 的变换：输出是一条 _直线_____
- 满秩 (full rank)：_变换后的向量空间维度没有下降_____

### 列空间 (column space)

- 列空间 = _矩阵各列_____ 的 span（用 Day 2 的语言说）
- 为什么"秩 = 列空间的维数"？_输出空间就是由变换后的基向量（=列）张成的_____

### 零空间 (null space)

- 零空间是所有 _被变换压到原点_____ 的向量的集合
- 满秩变换的零空间里只有 _零_____

### 我的疑问 / 卡点

-
>卡点一：秩与列空间的关系，秩表征了变换后实际到达空间的维数，决定了列空间（粗略理解为实际到达空间）的维数
>疑问一：矩阵的秩如何计算？秩不应该是在对一组基向量完成变换后才能清楚的结果吗？
- 答：秩的几何定义确实是变换后到达空间的维数，但存在纯代数事实：**秩 = 矩阵中线性无关的列数**（也等于行数）。看矩阵的列共不共线就行，不需要真的执行变换。直觉：列就是变换后基向量的落点，落点张成的空间就是输出空间。几何定义与代数算法在此接轨：**看矩阵的列，就是在看变换的输出**。
>疑问二："直觉：列就是变换后基向量的落点"，这个应该指的是向量矩阵吧？我不认为 A 表征了最终向量的落点。
- 答：对了一半——A 确实不表征任意向量 v 的落点（v 落哪是 A@v 的事，A 只提供新原料，配方来自 v 自己）。但我说的是**基向量** î、ĵ：M@[1,0] = 1·(第1列) + 0·(第2列) = 第1列，乘基向量就是"选出列"，所以 **A 的列 = î、ĵ 的落点**（Day 3 盲测里我正是靠这条事实构造出 M 的）。心里的结在于把"变换 A"和"记录落点的矩阵"当成两个东西——第 3 集的核心定理说它们是**同一个矩阵**：描述线性变换必需且只需知道基向量去哪了，落点并排写成列就完整编码了变换本身。"向量矩阵"和"变换矩阵"不是两类矩阵，是同一个矩阵的两种身份。
>疑问三：为什么 det=0 的塌缩图像在 `M @ basic_points` 之后才必然过原点，单独画 M 的列连线不行？
- 答：`draw_square(M)` 连接的是 Mî 和 Mĵ 两个落点之间的线段，是"新原料"的特写，过不过原点是巧合（两个落点恰好共线才在过原点的线上）；`M @ basic_points` 画的是整个正方形被变换后的命运，原点变换后永远在原点，所以塌缩像**必然过原点**。因果链：基向量共线（原因，det=0）→ 全空间被吸到一条过原点的直线上（效果，列空间塌成一维）。塌缩线 = 列空间 = 共线基向量的 span，span 必含原点（0·v = 0）。
>实验记录：对秩 1 矩阵 [[1,2],[2,4]] 求逆，NumPy 报 `LinAlgError: Singular matrix`——"被压缩的维度无法复原"的机器语言版。det=0 ⟷ 奇异 ⟷ 不可逆，同一事实的三种说法。
>遗留伏笔（待第 14 集回收）：A=[[2,1],[1,3]] 与它的逆在图上似乎沿某条线对称——无端猜测，可能与对称矩阵（Aᵀ=A）和它的逆共享特征方向有关。

## 今日总结（3 句话以内）

- det 回答"变换对空间做了什么"：绝对值是面积缩放率，符号是定向是否翻转，det=0 意味着空间被压缩（不可逆）；秩=列空间维数=无关列数，从矩阵的列直接可读
- Ax=v 是"用配方 x 混合 A 的新原料调出成品 v"：det≠0 时配方唯一（逆矩阵存在），det=0 时信息丢失，解 0 个或无限个
- 今天最重要的较真：A 的列 = 基向量的落点，"变换矩阵"和"向量矩阵"是同一个矩阵的两种身份——看矩阵的列就是在看变换的输出
