## 核心心智模型：两个仓库 + 一个邮差



  你的电脑（本地仓库）              GitHub（远端仓库）
  /mnt/d/study-space/Ai    ←push→   github.com/wayxi111/Ai
           ↑ pull←



• 本地仓库： .git  文件夹（被隐藏的那个）记录了完整历史。没网也能提交，Git 本身和
GitHub 无关
• 远端仓库：GitHub 上的一份拷贝，作用是备份 + 展示 + 多设备同步
•  origin  只是本地给远端起的别名——你昨天的问题就是 origin 指向了 wayci-bot
名下一个不存在的仓库
• 凭据（你是谁）：存在 gh CLI 里，当前是
wayxi111。推送到谁的仓库，就必须用谁的凭据——这就是昨天报错的根源

## 每天的使用循环（就这一张图）



  改文件 → git add（暂存） → git commit（存入本地历史） → git push（同步到GitHub）


VS Code 源代码管理面板对应关系：


 面板操作                  │ 等价命令                  │ 干什么
───────────────────────────┼───────────────────────────┼─────────────────────────────
 文件旁的 ＋               │  git add                  │ 放进“待提交清单”（暂存区）
 输入消息 + Ctrl+Enter     │  git commit -m "..."      │ 定格一个快照，只存本地
 Sync Changes 按钮         │  git push                 │ 把本地新 commit 送到 GitHub
 （拉取）                  │  git pull                 │ 把 GitHub 上新的更新拉下来

铁律：commit ≠ push。 commit 是本地存档，push 才上传。你可以在没网的地方攒 5 个
commit，回来一次 push。

## 每类东西该放哪


GitHub 仓库不是网盘，别人（包括未来的你）主要通过这些看项目：


 东西                │ 放哪                   │ 为什么
─────────────────────┼────────────────────────┼──────────────────────────────────────
 代码  .py   .ipynb  │ 仓库 ✅                │ 体积小、要追踪版本
 笔记  .md           │ 仓库 ✅                │ 推研时的能力证明，就是给人看的
  README.md          │ 仓库 ✅                │ 仓库门面，GitHub
                     │                        │ 页面首页显示的就是它
 数据集（MNIST 等）  │  .gitignore  排除 ❌   │ 体积大，且别人能自己下载
  .venv/             │ 已排除 ✅              │ 每台机器各建各的
 运行产出的图        │ 小图可提交，大量产物排 │ 看情况
                     │ 除                     │

## 你的仓库礼仪（学习仓库特别版）



1. commit 消息写清楚做了什么： week1: 手写两层MLP反向传播  远好于  update  ——
半年后你自己要靠它回忆
2. 一天至少一次 commit + push：push 了才叫备份。电脑坏了，GitHub 上的还在
3. 不用怕 commit 太碎：Git 的历史就是给你反悔用的， Ctrl+Shift+P → Timeline
能看到文件的所有历史版本
4. 暂时不用管分支（branch）——单人学习仓库，永远在 main 上干活即可，等做正经项目再学

## 验证你理解的三个问题



1. 昨天  git push  失败时，你本地那个 commit 丢了吗？（答：没有，commit 在本地，push
只影响同步）
2. 如果明天你在实验室电脑 clone 这个仓库，之后两台电脑怎么保持一致？（答：改完
push，换机器前 pull）
3.  git add  和  git commit  区别是什么？（答：暂存 vs 定格快照）

去 GitHub 上点开你的仓库看看：commits 页签里应该躺着  day1: environment setup
——那就是你本地历史的镜像。有具体操作卡住随时问。
