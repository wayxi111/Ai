## 知识主线

### 1. 频率与概率的三层身份

| 层 | dice | mini-batch |
|---|---|---|
| 真值（概率） | 各面 1/6（对称性先验） | 总体 loss L(W)=E[ℓ]，遍历分布，算不起 |
| 估计（频率） | N 次掷骰的面频 | batch 平均 (1/B)Σℓᵢ |
| 一次采样 | 掷一次 | 一个样本的 ℓ(xᵢ,tᵢ;W) |

- 概率是**被测量的量**，频率是**测量**；大数定律保证后者收敛到前者
- mini-batch loss = E[单样本损失] 的频率估计——**Day 8 的 /B 就是这个代换**：每个被抽中的样本占 1/B 权重
- 估计噪声 ~ σ/√B：B=64 抖 1/8；动量（EMA，窗≈10 步）再降 ~1/√10——**动量不只是惯性，同时是降噪器**（Day 8 实验结果的理论文档）

### 2. 期望：第一次从公式变成测量

- 定义（离散）：E[X] = Σᵢ xᵢ·pᵢ。等概率退化为算术平均（21/6=3.5）
- 实验均值 = 频率加权 Σxᵢ·(nᵢ/N)；N 大时频率→概率，故 mean→E[X]——**两个收敛是同一个大数定律**
- 记忆点：**期望是分布的重心，不是最可能的取值**——3.5 不是任何一面

### 3. 为什么被平均的随机变量是"单样本损失"

训练目标 = "任何图上的平均糟糕程度" = E[单次糟糕程度]。ℓ(x,t;W) 是**最小完整单元**：同时含 x、W、t，且语义是"糟"。对比：E[x]="平均图像"（灰雾）、E[t]=4.5（不含 W）、batch loss 是**估计工具**不是地基（用 L̂ 估计 L 而 L=E[L̂] 会循环定义）。

### 4. SGD 的 stochastic 出处

```
真更新：W ← W − lr·∇L(W)        ← 期望值，算不起
SGD ：W ← W − lr·∇L̂(W)        ← 频率估计，带噪声 ~1/√B
     = W − lr·[∇L + ε]
                  ↑随机项：阻碍 + 探索（鞍点逃逸，Week 3 后半回收）
```

- 单步噪声大（B=64 时 1/8 量级），但**累积相互抵消**（期望零，累积 ~√N×噪声）——"路程总账"越走越准
- 大 batch → 噪声位移 lr·σ/√B 小 → 可配大 lr：解释 Day 8 "lr 与 B 的配比约束"
- 无偏性：E[∇L̂] = ∇L（求和与求导交换）——SGD 是无偏估计，考研判断题素材
