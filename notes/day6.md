# Day 6 (2025-08-31)：dL/dW —— 第一块真正的硬骨头

> 今日主题：纸笔推导 y = xW + b 情形下的反向传播，并用手写代码验证。
> 这是整个深度学习的地基。规则：**每一步推导都写在纸上，填空只是誊写**。
> 口诀：链式法则 + 形状追踪（dL/dW 的形状必然和 W 一样）。

## 场景设定

单个样本 x（1×2 行向量），W（2×2），b（1×2）：

```
x = [x1, x2]              （1×2）
W = [[w11, w12],          （2×2）
     [w21, w22]]
b = [b1, b2]              （1×2）
y = xW + b                （1×2）
L = ½‖y − t‖²             （标量，t 是目标值）
```

## 第 0 步：前向传播展开（纸笔）

把 y 的两个分量显式写出来：

- y₁ = _x1w11+x2w21+b1_____
- y₂ = _x1w12+x2w22+b2_____

## 第 1 步：dL/dy（最容易的一步）

- L = ½(y₁−t₁)² + ½(y₂−t₂)²
- dL/dy₁ = _y1-t1_____，dL/dy₂ = _y2-t2_____
- 矩阵形式：dL/dy = _[y1-t1,y2-t2]_____（形状：__1x2____）

## 第 2 步：dL/db（热身）

- b₁ 只影响 y₁，所以 dL/db₁ = _y1-t1_____
- 结论：dL/db = _[y1-t1,y2-t2]_____（和 dL/dy 什么关系？_等价_____）

## 第 3 步：dL/dW（核心，分两条路走）

### 路 A：逐元素硬算（考试的路）

- dL/dw₁₁ = _x1(y1-t1)_____（w₁₁ 通过哪条路径影响 L？写出链条：w₁₁ → _y1___ → L）
- dL/dw₁₂ = _x1(y2-t2)_____
- 观察规律：dL/dw_ij = _x_i · (y_j − t_j)_____（第 i 行第 j 列的梯度 = 哪两个东西的外积？）

### 路 B：几何的路（用 Week 1 的直觉）

- xW 的第 j 列 = x 份配方混合 W 的第 j 列——W 的第 j 列影响 y 的第 _j___ 个分量
- 所以 dL/dW 的第 j 列 = _x*dL/dy 的第 j 个分量乘_____（dL/dy 的第 j 个分量乘上什么？）
- 矩阵形式：dL/dW = _x的转置点乘dL/dy_____（提示：x 是 1×2，dL/dy 是 1×2，谁的转置乘谁？）
- **形状追踪**：xᵀ (2×1) @ dL/dy (1×2) = (_2___×_2___)——和 W 的形状一致吗？完全一致

### 两条路对上了吗？

- 路A 的通项公式和路 B 的矩阵公式算的是同一个东西吗？_是一个_____

## 第 4 步：dL/dx（往下传的梯度）

- x 影响所有 y 分量：dL/dx₁ = dL/dy₁·w₁₁ + _dL/dy₂·w₁₂_____
- 矩阵形式：dL/dx = _[dL/dy₁·w₁₁+dL/dy₂·w₁₂,dL/dy₁·w₂₁+dL/dy₂·w₂₂]_____（dL/dy (1×2) 乘 W 的什么？形状：_1x2_____）
- 这就是"梯度穿过一层继续往前传"的机制——多层网络就是这步的接力

## 代码验证（day6 的验收标准）

- 按任务单实现 `dense_forward` / `dense_backward`
- **梯度检验**：数值梯度 `(L(W+εe_ij) − L(W−εe_ij)) / 2ε` 对比解析梯度，误差 < 1e-7
- 三个都验：dL/dW、dL/db、dL/dx

## 我的疑问 / 卡点

-
>卡点一（第 0 步就踩的坑）：我把 y₁ 写成了 x₁(w₁₁+w₂₁)+b₁——把"第 1 行相加"当成了输出，配方和原料的配对全乱了。正确：y₁ = x（整行配方）· W 第 1 列（原料）= x₁w₁₁+x₂w₂₁+b₁。**行号配行号**：w 的第 i 行跟着 x 的第 i 个分量走
>卡点二（病根记录）：本日 5 处错误（前向展开、db 被传染、通项丢 (y_j−t_j)、路B 出现幻觉下标 x_j、第 4 步两条路径都配了 dL/dy₁）全部同源——**下标配对**。口诀：梯度分量的下标跟"谁被求导"走，系数下标跟"路径"走
>卡点三（矩阵乘法的推广，问出来的好问题）：AB(m,k)@(k,n)——**中间维 k = 配料表长度，两边必须咬合**（这就是形状规则的全部真相）；m = 配方条数（A 的行），n = 原料份数（B 的列），各自传给结果。转置 = 把"行存"翻成"列存"，纯粹为咬合形状
>卡点四（前向/反向的真正含义）：
>• 前向 = **数据流**：原料→半成品→成品→评分，沿途存档（cache activations）
>• 反向 = **责任流**：δ = dL/d(本站输出) 从损失端原路返回。每站三件事：卸货 dL/dW = 本站输入ᵀ @ δ（外积=输入与责任的对齐度）、转发 δ_上游 = δ @ Wᵀ（转置是回程票）、有激活则先 ⊙σ'(h)
>• **边界换名 = 梯度传递的全部秘密**：下游算的 dL/d(我的输入)，在上游眼里就是 dL/d(我的输出)——同一个数，接力棒不需要制造
>• "流动"是计算顺序倒放，不是物理流动；反向本质 = δ 穿过转置的网络做第二次前向
>卡点五（形状追踪的边界）：第 4 步 (1×2)@(2×2) 对 W 和 Wᵀ 形状都合法，形状追踪判不了——必须靠下标模式。形状能排除大部分错误，但排除不了"转置与否"
>遗留伏笔：网络最外层的 dL/dx 通常丢弃（数据不是旋钮）——但对抗样本技术专门反过来调输入，三个月后回看

## 今日总结（3 句话以内）

- 从零推通了 y=xW+b 的全套梯度：dL/dW = xᵀ(dy)（外积视角）、dL/db = dy、dL/dx = (dy)Wᵀ，两条路径（逐元素硬算 + 列几何）互证一致
- 5 处错误同源于"下标配对"——修正过程本身就是最大的收获，比一次写对学到的多
- 建立了前向/反向的物流模型：数据流与责任流共用路网、边界换名传递梯度、转置永远落在被求导一侧的搭子头上
