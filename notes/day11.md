## 知识主线（今日四轮深究链）

### 1. CLT 与 √n 分母推导

- 工具三条：A1 期望线性 / A2 方差可加（独立时）/ A3 仿射 Var(aX+b)=a²Var(X)
- 链条：E[sₙ]=nμ → Var(sₙ)=nσ² → zn=(sₙ−nμ)/√(nσ²) 得 Var(zn)=1
- **√n 的来源：方差按平方单位相加，开根才回原量纲**。反例：除 n 则 Var(zn)=1/n，n=30 时 std=0.18，柱子越来越瘦永远叠不上 N(0,1)
- 四格全贴 N(0,1) 验的是 A2+A3；n=30 形状收敛验的是 CLT 补的形状板（0/1 是推导的货，形状是 CLT 的货）

### 2. cov vs corr

- 同：对称、中心化后波动方向探测器、独立⇒零、平移不变
- 异：cov 带单位（可算物理量，如 kV·A）、对缩放敏感；corr 无量纲 [−1,1]、缩放不动、跨实验可比
- **cov 是原材料，corr 和回归斜率是它的两种归一化**：corr 除 σx·σy（双向），斜率除 var(x)（单向）= 最小二乘解 w=cov/var(x)=0.8
- 陷阱：corr 只测线性（y=sin x 时 corr≈0 但强依赖）；corr=0 ≠ 独立；相关≠因果（共因）；σ=0 时 corr 无定义

### 3. 归一化处的会师

- 数据归一（σₓ=σᵧ=1）时 **cov 数值=corr 数值**——cov 的幅度层蒸发
- Transformer 的 LayerNorm/cosine attention = 让 cov 预制成 corr 的工程化（注意力只关心方向不关心幅度）
- 考研送分等式：标准化变量的协方差=相关系数

### 4. 读图五问（散点图的完整拆解）

1. 方向：椭圆主轴取向=cov 的几何住址
2. 宽度：噪声项带宽（0.3）
3. 斜率中心线：回归线 w=cov/var(x)
4. 疏密方向：联合概率质量长轴（等高线），corr=拉密程度
5. **位置 vs 形状 vs 尺度三分**（今日最高价值）：
   - 位置=均值住址（高斯宿命集中在 μ 处，与相关无关）
   - 形状=条件中心滑动轨迹（x 的信息注入 y）=相关性本体
   - 尺度=单位/σ（归一化管辖范围）
   - 眼睛爱把三者混读（"原点最密"被误读成相关性强）；反例：y2 独立对照样原点最密，只是正圆
- 条件分布：x∈(1.9,2.1) 窄条内 y 是小高斯，中心≈0.8·2=1.6 宽 0.3（Homoscedastic）；中心随 x 滑动轨迹=回归线；**这就是线性回归的预测动作**：知道 x 后 y 从大椭圆收紧成小竖条

### 5. 位置与构造式的关系（收官）

| 图上量 | 生成式成分 | 改谁会变 |
|---|---|---|
| 位置 | E[原料]=0 + **常数项** | 加 +5 立刻搬 |
| 尺度 | 系数 0.8/0.3 与原料 σ | 加大 0.3 云变胖 |
| 形状 | x 是否出现在 y 式中（耦合本身，0=独立）| 0.8→0 云散正圆 |

- **生成数据的代码=分布的全部参数**（和"12 均匀和造 N(6,1)"同构：写生成式=写定理）
- 平移对 corr 零贡献（定义中已中心化）；E[y]=0.8·E[x]+0.3·E[ε]=0（A1 一行记账）
