## 已建立的核心直觉

- 矩阵的列 = 基向量的落点；矩阵乘向量 = 用旧配方混合新原料
- det 度量面积/体积缩放；det=0 = 空间压缩降维（不可逆）
- 点积 = 投影 × 长度 = 方向一致度（三个月后 Q·K 的地基）
- 反向传播 = 责任流穿过转置网络；dL/dW = 输入 × 责任的外积（delta rule）
- 优化器 = 离散反馈控制（lr = 环路增益，电气老本行的暗道）
- 梯度消失/爆炸 = 回传矩阵连乘，每站缩放 s<1 衰减 / s>1 放大，深度是放大器
